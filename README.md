# По порядку — список задач

Небольшой адаптивный веб-сайт для повседневных дел. Создан как тестовое задание: добавить задачу, отметить выполнение, удалить и сохранить результат после обновления страницы.

## Возможности

- Добавление кнопкой или клавишей Enter без перезагрузки страницы.
- Проверка пустого ввода и ввода из одних пробелов.
- Очистка поля и возврат фокуса после добавления.
- Отметка выполнения и возврат задачи в активное состояние.
- Удаление любой задачи с предсказуемым перемещением клавиатурного фокуса.
- Сохранение текста и статуса в localStorage после каждого изменения.
- Счётчик задач и индикатор выполнения.
- Понятное состояние пустого списка.
- Перенос длинного текста, включая строки без пробелов.
- Синхронизация изменений между открытыми вкладками одного сайта.
- Сообщения об ошибке чтения или сохранения данных без остановки интерфейса.

## Технологии

HTML5, CSS3, JavaScript (ES6+), Web Storage API. Без фреймворков, внешних библиотек, сборщика и сетевых шрифтов. Все ресурсы находятся внутри проекта.

## Запуск

1. Скачайте и распакуйте архив.
2. Откройте терминал в папке `todo-list`.
3. Запустите статический сервер, например при установленном Python 3:

```bash
python3 -m http.server 8000
```

На Windows команда обычно выглядит так:

```powershell
py -m http.server 8000
```

4. Откройте `http://localhost:8000` в браузере.

Для быстрой визуальной проверки можно открыть `index.html` напрямую. Для проверки сохранения используйте HTTP-сервер: поведение localStorage для адресов `file://` зависит от браузера.

Установка npm-пакетов и сборка не нужны. Для размещения на статическом хостинге достаточно `index.html`, `styles.css`, `app.js` и папки `assets`.

## Доступность и данные

У поля есть видимая подпись, у кнопок удаления — доступные названия, у задач — нативные чекбоксы. Основные действия доступны с клавиатуры: Tab для переходов, Enter для отправки, Space для переключения чекбокса. Предусмотрены заметный фокус, сообщения для скринридера и отключение анимаций при `prefers-reduced-motion`.

Текст задачи добавляется через `textContent`, поэтому HTML в названии не исполняется. Загружаемые данные проверяются на ожидаемую структуру. Если сохранённые данные повреждены, сайт оставляет их нетронутыми и предупреждает, что новые изменения временные.

Ключ хранения: `po-poryadku.tasks.v1`. Задачи привязаны к браузеру и адресу сайта, не отправляются на сервер и не синхронизируются между устройствами. Очистка данных сайта удаляет задачи; приватный режим может ограничивать срок хранения. Два одновременных изменения в разных вкладках разрешаются по последнему сохранению.

При первом запуске список пуст. Демонстрационные задачи из проверки в исходники не включены.

## Проверка

Сценарии и фактические результаты описаны в [QA.md](QA.md). Синтаксис JavaScript можно дополнительно проверить при установленном Node.js:

```bash
node --check app.js
```

## Использованные AI-инструменты

**ChatGPT (Codex)** — разработка дизайна, HTML, CSS, JavaScript и документации, а также проверка сайта в браузере. Другие AI-инструменты при создании проекта не применялись.

## Публикация

Репозиторий содержит готовые исходники сайта. Для публикации на GitHub Pages выберите ветку `main` и каталог `/ (root)` в настройках Pages. Сборка не требуется.
