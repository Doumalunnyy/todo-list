# Проверка качества

Проверка выполнена 17 ноября 2026 года (Москва).

Среда: Chrome, локальный HTTP-сервер. Проверки выполнены через реальный интерфейс браузера. Адаптивность проверена на десктопной странице и в отдельных браузерных фреймах шириной 320 и 768 px; физические смартфоны и другие браузеры не использовались.

| Сценарий | Результат |
| --- | --- |
| Добавление через кнопку | Задача появляется, счётчик обновляется |
| Добавление через Enter | Задача появляется без перезагрузки |
| Очистка поля | После добавления поле пустое и готово к следующему вводу |
| Пустая строка и пробелы | Задачи не создаются; показано сообщение, фокус в поле |
| Выполнение | Чекбокс включается, текст зачёркивается, счётчик обновляется |
| Сохранение выполнения | После перезагрузки задача и отметка сохраняются |
| Отмена выполнения | После переключения и перезагрузки задача остаётся активной |
| Удаление | Задача исчезает и не возвращается после перезагрузки |
| Пустой список | После удаления последней задачи показана подсказка |
| Длинные названия | Обычный длинный текст и строка без пробелов переносятся |
| Узкий экран и планшет | При ширине фреймов 320/768 px горизонтального переполнения нет; scrollWidth равен clientWidth |
| Действия на узком экране | Добавление, выполнение, отмена и удаление работают |
| HTML в названии | `<b>Это текст, а не HTML</b>` отображается буквально; дочерних HTML-элементов в тексте задачи нет |
| Ошибки сайта | В журнале не обнаружены предупреждения или ошибки от страницы/скрипта сайта |
| Синтаксис JavaScript | `node --check app.js` завершился успешно |

В журнале окружения присутствовали сообщения расширения браузера `chrome-extension://`; они не относятся к коду сайта.

## Повторение основных сценариев

1. Запустите сайт по инструкции из README.
2. Нажмите «Добавить» с пустым полем, затем повторите с пробелами. Счётчик должен остаться нулевым.
3. Добавьте одну задачу кнопкой и вторую через Enter.
4. Отметьте первую, обновите страницу и проверьте обе задачи и отметку.
5. Снимите отметку, снова обновите страницу.
6. Удалите одну задачу, обновите страницу и убедитесь, что она не вернулась.
7. Введите длинный абзац и длинное слово без пробелов; проверьте страницу на узком экране.
8. Удалите все задачи и проверьте пустое состояние.
9. Пройдите по элементам клавишей Tab, переключите чекбокс клавишей Space.

## Ограничения проверки

Обработчики недоступного localStorage, повреждённого JSON и исчерпания квоты проверены по коду; эти сбои в браузере не имитировались. Полный аудит скринридером, проверка на физических устройствах, Safari и Firefox не проводились.
